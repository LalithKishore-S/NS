# Topology-aware early warning of cascading failures in interdependent networks

Two coupled networks (layers A and B, one-to-one dependency, Buldyrev et al. 2010) are attacked; failures cascade
between layers. Models never see the wiring — only aggregate failure fractions per half-step. We ask:

- **A.** Can the hidden generating family (ER / BA / WS / SBM) be identified from a partial cascade? → E2
- **B.** Can collapse be predicted early, beyond the obvious state? → E3, E4
- **C.** Does prediction transfer to a family never seen in training? → E5

## Install & run (CPU only)
```
pip install -r requirements.txt
make test          # 15+ tests: contracts, cascade invariants, no-leakage
make experiments   # full pipeline + every experiment (~35 min on 2 cores)
python run_experiments.py 05 06   # just some experiments (data already built)
```

## Layout
| path | owner | what |
|---|---|---|
| `common/` | both | contracts (pydantic + frozen trajectory schema), paths, dummy data, plotting colours |
| `person_a_sim/` | A | generators, coupling, cascade simulator, threshold analysis, `pipeline.py` entry point |
| `person_b_ml/` | B | features, mechanism classifier, collapse models A/B/C, evaluation, ablation |
| `experiments/` | — | one script per experiment (00–08) |
| `configs/grid.yaml` | — | experiment grid |
| `literature/` | — | reading map (paper → code), comparison matrix, per-step notes |
| `paper/` | — | draft |
| `DECISIONS.md` | — | every deviation from the plan, with the reason |

`artifacts/` (data) and `results/` (outputs) are regenerated by `make experiments` and not committed.
